# QED Smart Contract Language



## Features


- Basic Types like Felt, u32, bool, Array, Struct
- Functions
- Modules
- Traits
- Type Checking
- Generics
- Type Hint

## Getting Started

1. Run unit tests
```
make test
```

2. Run opcode tests
```
make interpret
```

3. Compile to `DPNFunctionCircuitDefinition`
```
make compile
```
