# QED Smart Contract Language



## Features


- Basic Types like Felt, Tuple, u32, bool, Array, Struct
- Functions
- Closures
- Constants
- Comptime
- If/Block/Match Expression
- Modules
- Traits
- Type Checking
- Generics
- Type Hint
- Trait Constraint
- Crate
- LSP

## Getting Started

1. Run unit tests
```
make test
```

2. Run examples
```
make interpret
```

3. Compile to `DPNFunctionCircuitDefinition`
```
make compile
```
