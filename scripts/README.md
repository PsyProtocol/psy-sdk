## Example command for installing prove-proxy
```shell
sudo ./install_prove_proxy.sh /qed_user_cli \
--user psy \
--group psy \
--create-user \
--num-proxies 3 \
--base-port 9990
```

## Example for uninstalling the prove-proxy systemd service
```shell
sudo ./uninstall_prove_proxy.sh --uninstall
```
